=== RÉPONSES DE L'UTILISATEUR ===

[SECTION: logical_components]
Les constituants logiques du BAS sont :

1. Calculateur : calculateur numerique.
   Role : traiter les commandes et les mesures pour reguler les vannes et communiquer l'etat du systeme.
   Ports d'entree : state data (information), energie (electrique), commande degivrage nacelle (information), consigne (P,T) (information), mesure temperature air (electrique), mesure pression air (electrique).
   Ports de sortie : state data (information), consigne ouverture vanne NAI (electrique), consigne ouverture vanne PCE (electrique), position vanne PCE (electrique).
   Fonctions : Provide Feedback, Reguler la PRV, Reguler la vanne NAI, Reguler la vanne PCE.

2. IP port : port d'interface d'entree.
   Role : point de prelevement de l'air chaud haute pression sur le compresseur du moteur.
   Port d'entree : air chaud haute pression (pneumatique, depuis le moteur).
   Port de sortie : air chaud haute pression (pneumatique, vers Vanne NAI et Vanne PCE).
   Fonction : Prelever air.

3. Vanne NAI : vanne pneumatique.
   Role : controler le passage de l'air chaud vers la nacelle pour le degivrage.
   Ports d'entree : consigne ouverture vanne (electrique, depuis Calculateur), air chaud haute pression (pneumatique, depuis IP port).
   Port de sortie : air chaud nacelle (pneumatique, vers ACAC).
   Fonction : Laisser passer l'air.

4. Vanne PCE : vanne pneumatique (actuated bleed select).
   Role : controler le passage de l'air chaud vers l'echangeur PCE pour la regulation en pression et temperature.
   Ports d'entree : consigne ouverture vanne (electrique, depuis Calculateur), position vanne PCE (electrique, depuis Calculateur), air chaud haute pression (pneumatique, depuis IP port).
   Port de sortie : air chaud haute pression (pneumatique, vers PCE).
   Fonction : Actuated bleed select.

5. PCE : echangeur thermique (Pressure Control Exchange).
   Role : transfert d'energie thermique entre l'air chaud moteur et l'air ambiant pour reguler la temperature.
   Ports d'entree : air chaud haute pression (pneumatique, depuis Vanne PCE), air ambiant (pneumatique, depuis l'environnement).
   Ports de sortie : air regule T (pneumatique, vers Air Pressure Sensor et Filter), air tiede (pneumatique, vers l'environnement).
   Fonction : Transfert d'energie thermique.

6. ACAC : echangeur thermique (Air Cooled Air Cooler).
   Role : reguler la temperature de l'air chaud nacelle en melangeant avec l'air ambiant.
   Ports d'entree : air chaud nacelle (pneumatique, depuis Vanne NAI), air ambiant (pneumatique, depuis l'environnement).
   Ports de sortie : air chaud nacelle (pneumatique, vers Nacelle port et ACAC Air Temperature Sensor), air tiede (pneumatique, vers l'environnement).
   Fonction : Reguler la temperature nacelle.

7. Filter : filtre pneumatique.
   Role : filtrer l'air regule avant distribution vers le systeme pneumatique avion.
   Port d'entree : air regule (P,T) (pneumatique, depuis PCE via Air Pressure Sensor).
   Port de sortie : air regule (P,T) (pneumatique, vers A/C pneumatic port).
   Fonction : Filtrer air.

8. PCE Air Temperature Sensor : capteur de temperature.
   Role : mesurer la temperature de l'air en sortie de l'ACAC/PCE cote avion.
   Port d'entree : air chaud nacelle (pneumatique).
   Port de sortie : mesure temperature air (electrique, vers Calculateur).
   Fonction : Mesurer la temperature (cote PCE).

9. Air Pressure Sensor : capteur de pression.
   Role : mesurer la pression de l'air regule en sortie du PCE.
   Ports d'entree : mesure de pression air (pneumatique, depuis PCE), air regule T (pneumatique).
   Port de sortie : mesure pression air (electrique, vers Calculateur).
   Fonction : Mesurer la pression.

10. ACAC Air Temperature Sensor : capteur de temperature.
    Role : mesurer la temperature de l'air chaud nacelle en sortie de l'ACAC.
    Port d'entree : air chaud nacelle (pneumatique, depuis ACAC).
    Port de sortie : mesure temperature air (electrique, vers Calculateur).
    Fonction : Mesurer la temperature (cote ACAC/nacelle).

11. Nacelle port : port d'interface de sortie.
    Role : fournir l'air chaud regule a l'interface de la nacelle.
    Port d'entree : air chaud nacelle (pneumatique, depuis ACAC).
    Port de sortie : air chaud nacelle (pneumatique, vers la nacelle).
    Fonction : Fournir l'air a l'interface Nacelle.

=== RÈGLES MÉTIER ===

R1 — CONSTITUANTS AVEC PORTS : Chaque constituant logique doit avoir au moins un port. Si l'utilisateur n'a pas précisé les ports, ajouter un warning "missing_info".

R2 — ALLOCATION COMPLÈTE : Chaque fonction feuille du niveau fonctionnel doit être allouée à exactement un constituant. Si des fonctions ne sont pas allouées, ajouter un warning "missing_info". Si une fonction est allouée à un constituant qui n'existe pas, ajouter un warning "inconsistency".

R3 — COHÉRENCE DES CONNEXIONS : Chaque connexion doit référencer des ports existants sur des constituants existants. Si une connexion référence un port ou constituant inexistant, ajouter un warning "inconsistency".

R4 — TYPAGE DES PORTS : Chaque port doit avoir une direction (in/out/inout) et un flow_type. Le flow_type doit être cohérent avec les flux fonctionnels du niveau précédent.

R5 — REGROUPEMENT : Si l'utilisateur mentionne des sous-systèmes, utiliser la structure children[] récursive de LogicalComponent pour représenter la hiérarchie.

R6 — EXIGENCES : Les exigences logiques doivent avoir un ID au format REQ-LOG-XXX. Le champ satisfied_by doit référencer un constituant existant.

	private import ISQ::*;
	private import 'Calculation Definitions'::*;
	
	part def VehicleDynamics {
		attribute C_d : Real;
		attribute C_f : Real;
		attribute wheelPower : PowerValue;
		attribute mass : MassValue;
		
		action straightLineDynamics {
			in delta_t : TimeValue;
			in v_in : SpeedValue;
			in x_in : LengthValue;
			out v_out : SpeedValue = vel.v;
			out x_out : LengthValue = pos.x;
		
			calc acc : Acceleration {
				in tp = Power(wheelPower, C_d, C_f, mass, v_in);
				in tm = mass;
				in v = v_in;
				return a;
			}
			
			calc vel : Velocity {
				in dt = delta_t;
				in v0 = v_in;
				in a = acc.a;
				return v;
			}
			
			calc pos : Position {
				in dt = delta_t;
				in x0 = x_in;
				in v0 = vel.v;
				return x;	
			}
		}
	} 
	
}
